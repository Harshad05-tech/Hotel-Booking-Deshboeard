# Hotel-Booking-cancellation-reason

<b>Project Overview</b><br>
-  This project involves transforming a raw <br> 
   Dataset : https://www.kaggle.com/datasets/mojtaba142/hotel-booking <br>
   into a structured format to analyze why after hotel reservation cancellations <br>
   using Microsoft Excel

<b>Project Objectives</b><br>
- Clean and transform messy raw data into a usable format. <br>
- Identify key trends through Pivot Tables. <br>
- Create an interactive visual dashboard for cancellations reason. <br>

<b>Tech Stack & Tools</b>
- Software: Microsoft Excel <br>
- Techniques used: Data Cleaning, Pivot Tables, Conditional Formatting, Data Visualization (Charts).
